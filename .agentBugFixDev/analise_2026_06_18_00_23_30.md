## Diagnosis

A truncated UTF-8 sequence in `looksLikeUtf8` can cause the method to read past the end of the byte array, producing `ArrayIndexOutOfBoundsException` when header values contain single non-ASCII bytes (e.g., ISO-8859-1 encoded `é`). The function had no bounds check for expected continuation bytes.

## Correction

- File modified: `src/main/java/org/jsoup/helper/HttpConnection.java`
- Change: added a guard `if (end >= j) return false;` before reading continuation bytes in `looksLikeUtf8` to prevent out-of-bounds access and treat truncated sequences as non-UTF-8.
- Test added: `src/test/java/org/jsoup/helper/HttpConnectionTest.java` — `addHeaderSpecialChar()` verifies adding a header with `"é"` does not throw and preserves the header value.

Rationale: minimal safe fix that prevents the exception and preserves previous behavior for valid UTF-8 sequences.
