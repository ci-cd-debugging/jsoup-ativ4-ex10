## Diagnosis

The crash was caused by an incomplete bounds check inside `looksLikeUtf8()`. A single-byte ISO-8859-1 header value such as `é` was treated as the start of a longer UTF-8 sequence, and the continuation-byte loop read beyond the array bounds.

## Fix

I added a regression test in `src/test/java/org/jsoup/helper/HttpConnectionTest.java` for `req.addHeader("xxx", "é")` and updated `src/main/java/org/jsoup/helper/HttpConnection.java` so `looksLikeUtf8()` returns `false` when the inferred UTF-8 sequence would exceed the available bytes. This preserves the original header value instead of crashing.
